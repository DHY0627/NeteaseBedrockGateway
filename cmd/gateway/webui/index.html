全局设置

添加账号
账号密码会以明文保存在网关的配置文件里（与命令行 -u/-p 等价）， 请确保该文件权限收紧（chmod 600）。
创建实例
玩家流量的转发目标（Geyser 的 RakNet 端口）。
创建命令行
按 /bin/sh -c 执行（Windows 下由 cmd /c 执行）。 点击下面的占位符可插入到光标处，执行时会被替换成实际值。
网关日志
默认只输出关键事件（登录 / 建房 / 玩家进出 / 保活）。要看到逐帧 hex、pion(ICE/DTLS/SCTP) 与 NetherNet 信令细节，请在实例的启动参数里加 -d 或 --debug。
